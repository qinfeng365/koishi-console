# Koishi Console Plugin

This repository is a standalone copy of [`plugins/console`](https://github.com/koishijs/webui/tree/main/plugins/console) from the Koishi WebUI project, maintained here for personal modifications.

## Development

Install dependencies with your preferred package manager, then run the TypeScript checks with:

```bash
npx tsc -p tsconfig.json --noEmit
```
